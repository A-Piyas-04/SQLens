
# SQLens

**An interactive and visual approach to learning SQL.**

SQLens is an open-source SQL learning project designed to help beginners understand SQL concepts through visual demonstrations and hands-on practice.

Instead of simply writing queries and viewing their outputs, SQLens provides an interactive environment where learners can explore how SQL queries work through animated simulations.

🌐 **Live Demo:** https://sq-lens-phi.vercel.app/

## Features

- **Interactive SQL Playground:** Write and execute SQL queries in your browser.
- **Visual Query Simulations:** Explore SQL execution through animated, step-by-step demonstrations.
- **Hands-on Practice:** Experiment with queries and learn through practical exercises.
- **Database Explorer:** Browse tables, columns, and database structures.
- **ER Diagram Visualization:** Understand relationships between database tables through visual diagrams.
- **Sample Databases:** Get started with preloaded datasets and SQL examples.
- **Query History:** Keep track of previous queries while practicing.
- **Browser-Based Experience:** Start learning without complicated setup or account creation.

## Getting Started

### Prerequisites

- Node.js 20 or later
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/A-Piyas-04/SQLens.git
cd SQLens
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite, usually:

```text
http://localhost:5173
```
