PHASE 5 — Stage choreography (plan §3, §9, §15 Phase 5)
======================================================================
[x] 5.0  Shared motion helpers; compositor-friendly (transform/opacity only); no blur
[x] 5.1  FROM: fade + translateY(10px→0), 250–350ms, tiny cascade only if few rows,
         no max-height reveal
[x] 5.2  WHERE: focus predicate columns; sequential evaluation ✓/✕ marks; failing rows
         red tint → ✕ → translateX(24px) → opacity 0 → collapse; survivors stay calm;
         result "N rows → M rows" + "k rows removed by <cond>"
[x] 5.3  HAVING: same grammar on groups; focus aggregate columns; "N groups → M groups"
[x] 5.4  LIMIT: single cutoff marker after row N; rows below fade/move out; collapse;
         no per-row badges
[x] 5.5  SELECT: selected columns emphasised, dropped dimmed; dropped columns (header +
         body) leave; survivors translate to final position; final columns exact
[x] 5.6  ORDER BY: same DOM nodes glide old Y → new Y; no fade replacement;
         subtle ↑/↓ hint for significant movers; sort columns focused
[x] 5.7  GROUP BY A Focus: only grouping keys + aggregate inputs (+ identifying column)
[x] 5.8  GROUP BY B Gather: rows move physically into group containers
[x] 5.9  GROUP BY C Aggregate: show inputs → aggregate result (AVG/SUM/COUNT/MIN/MAX)
[x] 5.10 GROUP BY D Collapse to grouped result rows
[x] 5.11 GROUP BY fallback when aggregates can't be mapped (still gather + collapse)
[x] 5.12 JOIN layout: LEFT | MATCH LANE | RIGHT; key columns + compact identity
[x] 5.13 JOIN one active match at a time; "✓ Match found"; compact combined row
[x] 5.14 JOIN previous arrows dimmed to ~0.2 opacity
[x] 5.15 JOIN one-to-many fan-out + "N matches" summary
[x] 5.16 JOIN LEFT JOIN null: dashed stub → "no match" → NULL
[x] 5.17 JOIN curved cubic-Bézier <path>; draw-on via strokeDasharray/offset (getTotalLength)
[x] 5.18 JOIN uses global controller (pause/speed/cancel/completion)
[x] 5.19 JOIN resize: anchors re-measured, no stale coordinates
[x] 5.20 Every stage's settled visual state equals the snapshot (rows, columns, count)
